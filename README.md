# Expense Tracker

A responsive expense tracking application built with HTML, CSS, and vanilla JavaScript.

## Features

- Add and delete income and expense transactions
- Automatically calculate total income, expenses, and net balance
- Search, filter, and sort transactions
- Track monthly budgets by category
- Visualize income and expenses with interactive charts
- View monthly financial reports
- Switch between light and dark themes
- Choose a preferred currency symbol
- Save transactions, budgets, and preferences using localStorage
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage API
